useState is the most commonly used React Hook. It lets a component store data that can change over time. When that data changes, React re-renders the component and updates the UI.
Things to remember
✅ Import useState.

✅ Create state using:

const [value, setValue] = useState(initialValue);
✅ Use the state variable to display data.
✅ Use the setter function to update the state.
✅ Updating state causes React to re-render the component.
❌ Never update the state directly.

Wrong:

count = count + 1; // ❌

Correct:

setCount(count + 1); // ✅
